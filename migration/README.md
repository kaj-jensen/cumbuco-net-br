# WordPress content migration

This folder records the pre-design migration from the live WordPress site.

- `raw/properties.json` and `raw/pages.json` are the untouched rendered-page exports.
- `inventory.json` is generated by `npm run content:prepare` and records counts and legacy routes.
- `content-architecture.md` defines the page hierarchy and navigation before visual design.
- `content-review.md` records catalogue, editorial, and legal decisions still needed before launch.
- `src/content/properties/` and `src/content/pages/` contain the Astro-ready entries.
- `public/images/properties/<slug>/originals/` contains the original WordPress gallery uploads.

The generated property entries retain the WordPress URL, post ID, canonical and SEO metadata, description HTML and text, taxonomies, specifications, features, map coordinates, video ID, availability dates, original image URL, and new local image path.

Do not edit generated collection entries directly. Correct the raw export or transformation script and run `npm run content:prepare` again.
