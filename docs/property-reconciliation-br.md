## Regras para a migração

- Preservar todas as URLs brasileiras de imóveis que permanecerem ativas.
- Redirecionar uma URL somente depois de confirmar que o imóvel foi removido, renomeado ou consolidado.
- Quando os números divergirem, usar o cadastro inglês. Para Jardim Reale, usar o cadastro brasileiro até existir uma contraparte inglesa.
- Manter as imagens originais com proveniência; escolher e otimizar derivados apenas na etapa visual.
- Não publicar preços, taxas ou disponibilidade histórica sem confirmação atual.
